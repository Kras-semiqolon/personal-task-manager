## Project Description

The Personal Task Manager is a simple Laravel web application that allows users to organize and manage their daily tasks. Users can create tasks, view task details, edit existing tasks, delete tasks, and update each task's status.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Task Status
  - Pending
  - Completed

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- Git
- GitHub Codespaces

## Task Information

Each task contains:

- Task Name
- Description
- Status
- Due Date

## How the System Works

The system uses Laravel's MVC structure:

- **Routes** handle the application URLs.
- **Controller** processes task actions.
- **Model** communicates with the database.
- **Database** stores task information.
- **Blade Views** display the user interface.
